从零写一个 Agent（04）：实现工具调用循环和命令行入口

本篇把上一章的 read_sample 连到 Responses API。模型只看到一个读预置文本的工具，程序用固定分支执行它，最多执行三轮。网页展示代码，不在浏览器里运行。

一次工具调用的三个步骤

  1. 把任务和 read_sample_tool 的说明发给模型。
  2. 从输出中筛出 function_call，验证工具名和参数后，在 Python 中执行只读函数。
  3. 用本轮的响应 ID 继续会话，用调用 ID 关联具体的工具结果。

两种 ID 有不同用途：previous_response_id 关联整轮响应，call_id 关联某一次函数调用。下一章会并排展示这些字段。

实现有上限的只读循环

将本例与上一章的 read_sample 和 read_sample_tool 放在同一模块。可传入模拟客户端测试，不需要真实密钥。

import json


def run_agent(client, model: str, prompt: str) -> str:
    request_input = prompt
    previous_response_id = None

    for round_index in range(4):
        response = client.responses.create(
            model=model,
            input=request_input,
            tools=[read_sample_tool],
            previous_response_id=previous_response_id,
            parallel_tool_calls=False,
        )
        if response.status != "completed":
            raise RuntimeError("Model response did not complete")

        calls = [item for item in response.output if item.type == "function_call"]
        if not calls:
            return response.output_text
        if round_index == 3:
            break

        request_input = []
        for call in calls:
            try:
                arguments = json.loads(call.arguments)
                if call.name != "read_sample" or arguments != {"name": "pyproject"}:
                    raise ValueError("Tool or arguments not allowed")
                result = {"text": read_sample("pyproject")}
            except (ValueError, TypeError):
                result = {"error": "Only the built-in pyproject sample is supported"}
            request_input.append({
                "type": "function_call_output",
                "call_id": call.call_id,
                "output": json.dumps(result, ensure_ascii=False),
            })
        previous_response_id = response.id

    raise RuntimeError("Reached the tool round limit")

测试时模拟两轮响应：第一轮返回工具请求，第二轮返回文本。断言传回的 call_id 与第一轮一致；另外模拟未知工具、无效参数和轮数超限。

接到命令行入口

在第 1 篇已有的 main() 中，用标准库 argparse 接收任务文字和模型名。可以先让 --help 工作，用模拟客户端跑通调用循环，再考虑在自己的环境里连接真实 API。公开网页不绑定真实账号，也不代理 API 请求。
